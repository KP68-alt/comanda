# Comanda

From menu to money, one scan. A concept site for Comanda: an AI menu builder that hosts a restaurant's menu behind a QR code on every table and runs the payment when guests pay from their phone.

Live: https://kp68-alt.github.io/comanda/

Static site, no build step. 3D scene built with [three.js](https://threejs.org) (MIT, vendored in `vendor/`). Fonts: Archivo and Martian Mono (SIL OFL, in `fonts/`).
